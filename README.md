Выпускник 2026 года по направлению **«Программная инженерия»**
(КНИТУ-КАИ им. А. Н. Туполева, Казань, ИКТЗИ).

Делаю полный цикл: от вёрстки и React-компонентов до API на ASP.NET Core, схемы базы в PostgreSQL и миграций EF Core. Люблю, когда код покрыт тестами и когда поведение системы описано до того, как написан первый класс.

- 🏆 **2-е место на хакатоне** — фронтенд мини-приложения и админ-панели на React, интеграция с бэкендом на C# / Entity Framework через REST API
- 🧪 Пишу тесты **до** кода: TDD, спецификации, Testcontainers с настоящим PostgreSQL
- 🌱 Быстро учусь, держу сроки, спокойно работаю в команде и с чужим кодом
